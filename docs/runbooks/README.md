# Runbooks

- [`incident-communication.md`](incident-communication.md) — what to
  monitor during a pause, how to investigate, escalation timing, who to
  notify and when, and the post-incident review process. Builds on
  [`docs/emergency-operations.md`](../emergency-operations.md), which is the
  on-chain specification this runbook assumes.
- `post-incident/` — completed post-incident reviews, one file per incident,
  using the template in `incident-communication.md`. Created on first use;
  does not exist until an incident has actually happened.
